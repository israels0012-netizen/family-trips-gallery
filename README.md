# סוסובר — מסביב לעולם ביום אחד

אתר גלריה לטיולים המשותפים של המשפחה. בוחרים טיול, נכנסים, ורואים את כל התמונות
במסך מלא — יחד עם הסיפור, התאריכים והמשתתפים.

האתר בנוי HTML/CSS/JS סטטי בלבד: אין תהליך בנייה, אין תלויות, ואפשר לארח אותו
בחינם ב-GitHub Pages.

---

## הפעלה מקומית

פשוט פותחים את `index.html` בדפדפן. אם משהו לא נטען כמו שצריך (בגלל הגבלות של
הדפדפן על קבצים מקומיים), אפשר להריץ שרת קטן מתיקיית הפרויקט:

```bash
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

## פרסום ב-GitHub Pages

1. בריפו: **Settings → Pages**
2. תחת *Build and deployment* בוחרים **Deploy from a branch**
3. בוחרים את הענף (למשל `main`) ואת התיקייה `/ (root)` ולוחצים **Save**
4. אחרי כדקה האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/family-trips-gallery/`

---

## הוספת טיול חדש

כל התוכן של האתר יושב בקובץ אחד: **`assets/js/data.js`**.

1. צרו תיקייה חדשה לתמונות: `images/<שם-באנגלית>/` (למשל `images/paris/`)
2. העתיקו לתוכה את התמונות
3. הוסיפו בלוק חדש למערך `TRIPS` בקובץ `assets/js/data.js`:

```js
{
  slug: 'paris',                       // מזהה באנגלית — חייב להיות ייחודי, מופיע בכתובת
  title: 'פריז',
  country: 'צרפת',
  region: 'אירופה',                    // משמש לכפתורי הסינון בעמוד הבית
  year: 2026,
  dateLabel: 'מאי 2026',
  days: 5,
  summary: 'משפט קצר שמופיע על הכרטיס ובראש עמוד הטיול.',
  story: 'הסיפור המלא של הטיול — פסקה חופשית.',
  participants: ['אבא', 'אמא', 'הילדים'],
  cover: 'images/paris/01.jpg',        // תמונת השער של הטיול
  photos: [
    { src: 'images/paris/01.jpg', caption: 'כיתוב שמופיע מתחת לתמונה' },
    { src: 'images/paris/02.jpg', caption: '' }
  ]
}
```

זהו — הכרטיס בעמוד הבית, עמוד הטיול, הגלריה, ציר הזמן והסינון מתעדכנים אוטומטית.

### החלפת תמונות הדמו

התמונות שבתיקיית `images/` כרגע הן איורי דמו (קובצי `.svg`) שנוצרו כדי שאפשר
יהיה לראות איך האתר נראה לפני שמעלים תמונות אמיתיות.

כדי להחליף: מעלים את התמונות האמיתיות לתיקייה של הטיול ומעדכנים את הנתיבים
ב-`data.js` (למשל `images/santorini/01.svg` ← `images/santorini/01.jpg`).

מומלץ לדחוס תמונות לרוחב של כ-2000px לפני ההעלאה, כדי שהאתר יישאר מהיר.

> אם בכל זאת רוצים לחדש את איורי הדמו: `python3 tools/make_placeholders.py`

## מבנה הפרויקט

```
index.html                 עמוד הבית — Hero, נתונים, גלריית הטיולים, ציר זמן
trip.html                  עמוד טיול בודד — נטען לפי ?trip=<slug>
assets/css/style.css       כל העיצוב (צבעים, טיפוגרפיה, רספונסיביות)
assets/js/data.js          ← כאן עורכים תוכן: טיולים ותמונות
assets/js/app.js           לוגיקה משותפת: תפריט, כותרת דביקה, אנימציות
assets/js/home.js          עמוד הבית: סינון, חיפוש, ציר זמן, מונים
assets/js/trip.js          עמוד הטיול
assets/js/lightbox.js      תצוגת מסך מלא
images/<slug>/             תמונות הטיול
tools/make_placeholders.py יוצר את איורי הדמו
```

## מה יש באתר

- **גלריית טיולים** עם סינון לפי אזור וחיפוש חופשי (יעד, מדינה, שנה)
- **עמוד לכל טיול** עם תאריכים, יעד, משך, משתתפים, סיפור ופסיפס תמונות
- **לייטבוקס מסך מלא** — ניווט בעכבר, בחיצי המקלדת (`←`/`→`, `Esc` לסגירה) ובהחלקה בנייד
- **ציר זמן** כרונולוגי של כל המסעות
- עיצוב נייבי־זהב, RTL מלא, תמיכה מלאה בנייד ובקורא מסך
