# 🥽 VR Player

נגן וידאו שרץ בדפדפן ומתאים **כל סרטון שמעלים וכל קישור שמדביקים** למשקפי VR —
בלי המרות, בלי התקנות, ובלי להעלות שום דבר לשום שרת.

---

## מה הוא עושה

כשטוענים סרטון האפליקציה מזהה בעצמה איך הוא מצולם, ובונה לפי זה את הסצנה
במשקפיים:

| מה מזוהה | מה קורה בפועל |
| --- | --- |
| סרטון רגיל (2D) | מסך קולנוע מעוקל שצף מולכם בחדר חשוך — אפשר לכוון גודל, מרחק וקימור |
| 180° | חצי כדור עוטף מלפנים |
| 360° | כדור מלא — מסתכלים לכל כיוון |
| תלת־ממד «זה לצד זה» (SBS) | כל חצי מהתמונה נשלח לעין אחרת |
| תלת־ממד «אחד מעל השני» (TB) | אותו דבר, בחלוקה אופקית |

הזיהוי מצליב שני מקורות מידע: רמזים בשם הקובץ או בקישור (`VR180`, `SBS`,
`360`, `over-under` וכו׳) ויחס הממדים של הווידאו עצמו. כל אפשרות מקבלת ניקוד,
כך שרמז מפורש בשם יכול לגבור על יחס ממדים מטעה ולהפך. אם הזיהוי בכל זאת פספס —
יש כפתורים ידניים, והבחירה שלכם **נשמרת לאותו סרטון** ותחזור אוטומטית בפעם הבאה.

## איך משתמשים

1. מריצים את התיקייה כאתר (ראו «הרצה» למטה) ופותחים את הכתובת.
2. גוררים סרטון פנימה, בוחרים קובץ, או מדביקים קישור — אפשר פשוט ללחוץ
   <kbd>Ctrl</kbd>+<kbd>V</kbd> בכל מקום בדף.
3. לוחצים «כניסה ל‑VR».

**במשקפיים (Quest, Pico, Vive וכל דפדפן עם WebXR):** פותחים את אותה כתובת
בדפדפן של המשקפיים. בתוך ה‑VR יש לוח שליטה צף:

| פעולה | שליטה |
| --- | --- |
| פתיחה וסגירה של הלוח | כפתור עליון בשלט (A/X/B/Y) או הכפתור הצדי |
| בחירה | מכוונים עם קרן השלט ולוחצים על ההדק |
| הרצה קדימה ואחורה | ג׳ויסטיק ימינה / שמאלה |
| קירוב והרחקה של המסך | ג׳ויסטיק למעלה / למטה (במצב מסך שטוח) |

מהלוח אפשר גם להחליף סוג הקרנה, להחליף בין העיניים, ולמרכז את התמונה מחדש —
בלי להוריד את המשקפיים.

**טלפון עם מסגרת קרדבורד:** לוחצים על «📱 קרדבורד». המסך מתפצל לשתי עיניים
והתמונה עוקבת אחרי תנועת הראש.

**מקשים במחשב:** <kbd>רווח</kbd> נגן/השהה · <kbd>←</kbd> <kbd>→</kbd> דילוג ·
<kbd>M</kbd> השתקה · <kbd>R</kbd> מרכוז · <kbd>S</kbd> הגדרות · <kbd>F</kbd> מסך מלא.

## אילו מקורות עובדים

* **קבצים מהמכשיר** — MP4, WebM, MOV, M4V וכל מה שהדפדפן יודע לנגן.
  הקובץ לא עולה לשום מקום; הוא נפתח ישירות מהדיסק.
* **קישורים ישירים** לקובץ וידאו, וגם שידורי **HLS** (`.m3u8`).
* **מה שלא יעבוד, ולמה:** קישורי YouTube, Vimeo, פייסבוק, אינסטגרם או דרייב.
  האתרים האלה לא חושפים את קובץ הווידאו עצמו לאתרים אחרים, וזה לא משהו שאפשר
  לעקוף מהצד שלנו. האפליקציה מזהה את המקרים האלה ואומרת את זה במפורש במקום
  להיתקע. הפתרון: מורידים את הסרטון למכשיר וגוררים אותו פנימה.
* קישור ישיר עלול להיכשל גם אם השרת שלו לא שולח כותרת CORS — הדפדפן לא מרשה
  להקרין וידאו כזה בתלת־ממד. גם על זה מתקבלת הודעה מפורשת.

## הרצה

צריך שרת HTTP — הדף בנוי ממודולי ES, והם לא נטענים מ‑`file://`.

```bash
cd vr
npm run dev          # http://127.0.0.1:8080/index.html
```

לצפייה מהמשקפיים צריך שהמשקפיים והמחשב יהיו באותה רשת, ואז לפתוח את כתובת ה‑IP
של המחשב. שימו לב ש‑WebXR דורש **HTTPS** בכל כתובת שאינה `localhost`, ולכן
לשימוש קבוע הכי פשוט להעלות את התיקייה לאירוח סטטי כלשהו (למשל GitHub Pages).

אין שלב בנייה ואין תלויות בזמן ריצה: `three.js` ו‑`hls.js` שמורים בתוך
`vendor/`, כך שהאפליקציה עובדת גם בלי גישה ל‑CDN.

## בדיקות

```bash
cd vr
npm install          # playwright, לבדיקות הדפדפן בלבד
npm test
```

* `tests/detect.test.mjs` — שמות קבצים אמיתיים מול ההקרנה שמצפים לה.
* `tests/browser.test.mjs` — מריץ את האפליקציה בדפדפן אמיתי ובודק את הדברים
  שאי אפשר לראות מקוד: שהתמונה לא הפוכה ולא מראה, שהחצי הנכון מגיע לעין הנכונה,
  שרקע החדר לא מכסה את הסרטון, ושכל כפתור בלוח ה‑VR נתפס בקרן של השלט.
